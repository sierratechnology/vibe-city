PLANETARY EXPEDITION · SEPTEMBER 2026

Servers & rules

The current server admits up to 50 concurrent characters. Public server creation remains disabled. The verified server owner can appoint admins and moderators to verified accounts. See the Admin Tools guide for role permissions and instructions.

Rules

PvP, building damage and offline raiding are enabled by default. Players may choose peaceful cooperation or conflict. A structure PIN controls access, not invulnerability. The current prototype respawns defeated players at landing with their inventory retained; corpse loot and persistent offline sleeper bodies are not implemented.

Administration

Terminal → Server contains validated settings for capacity, PvP, structure damage, offline raiding, resource gathering, survival consumption, day/night duration, required sleepers and rover speed. The server checks permissions for every change. Only the owner can grant or revoke staff roles. Admins and moderators can ban or unban ordinary accounts; changes are audited.

Seed, planet size, gravity and atmosphere generation are fixed for an existing world. Future creation settings must configure those before generation. No setting silently resets the current world.

Saves

Active world changes save frequently. A daily snapshot is scheduled for 00:00 UTC, with eight days of retention. Existing accounts, characters and constructions are migrated in place.

Admin Tools

Open Field Guide → Admin Tools. The verified owner can assign account usernames as Admin, Moderator or Player. Admins can quick-build without costs, spawn 1–200 resource or supply units into their own backpack or onto nearby ground, refill their survival meters, change server settings, and ban or unban ordinary players. Moderators can ban and unban ordinary players only. Only the owner can assign roles or moderate staff. Every privileged request checks current account authority and is recorded. Bans disconnect active players within 30 seconds.

Quick build keeps grid, support, range, collision and world-capacity checks. The backpack still holds 60 units. Structure moving, admin undo, flight and teleport tools are not included in this release.

This is a developing playable prototype. Planned systems are identified separately from implemented features.
