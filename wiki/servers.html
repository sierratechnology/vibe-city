PLANETARY EXPEDITION · SEPTEMBER 2026

Servers & rules

The current server admits up to 50 concurrent characters. Public server creation remains disabled. The server master can appoint administrators after their accounts verify an email.

Rules

PvP, building damage and offline raiding are enabled by default. Players may choose peaceful cooperation or conflict. A structure PIN controls access, not invulnerability. The current prototype respawns defeated players at landing with their inventory retained; corpse loot and persistent offline sleeper bodies are not implemented.

Administration

Terminal → Server contains validated settings for capacity, PvP, structure damage, offline raiding, resource gathering, survival consumption, day/night duration, required sleepers and rover speed. The server checks permissions for every change. Only the master can grant or revoke admin roles. Admins can ban ordinary accounts; changes are audited.

Seed, planet size and atmosphere generation are fixed for an existing world. Future creation settings must configure those before generation. No setting silently resets the current world.

Saves

Active world changes save frequently. A daily snapshot is scheduled for 00:00 UTC, with eight days of retention. Existing accounts, characters and constructions are migrated in place.

Terms · Privacy

This is a developing playable prototype. Planned systems are identified separately from implemented features.
